# LabProxy TUI 设计评审标准

## 评审维度

### Design Quality (权重: 0.35)
- 浅色背景下所有文字清晰可读
- 颜色搭配和谐，不刺眼
- 信息层次分明（标题 > 正文 > 辅助信息）
- 无边框、无装饰线，纯靠颜色和间距区分
- 留白充足，不拥挤

### CJK Alignment (权重: 0.25)
- 所有视图中混合中英文文本列对齐
- 导航栏中文标签宽度一致
- 列表项名称+值对齐
- 配置页标签+值对齐
- 无任何肉眼可见的错位

### Craft (权重: 0.25)
- 代码结构清晰，主题 token 语义化
- 支持深色/浅色双模式
- `tea.RequestBackgroundColor` 自动检测
- 样式定义集中管理，无重复
- 所有现有测试通过

### Functionality (权重: 0.15)
- 5 个视图（代理/连接/日志/规则/配置）完整渲染
- 帮助浮层正常
- 搜索过滤正常
- 导航切换正常
- 所有交互功能不受影响

## 评分标准

| 分数 | 含义 |
|------|------|
| 9-10 | 优秀，可作为设计参考 |
| 7-8 | 良好，有小问题 |
| 5-6 | 可接受，有明显问题 |
| 3-4 | 差，需要大幅修改 |
| 1-2 | 不可用 |

## 通过阈值: 7.5 (加权平均)
